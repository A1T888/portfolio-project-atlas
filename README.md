# Project ATLAS — Hosting Migration & Network–Cyber Resilience Programme

A scoped, audit-ready infrastructure transformation programme for a global investment firm's 24×7 operations.

## What this is

An 18-month, S$8.5M programme covering data centre migration (on-prem → colocation + cloud), SD-WAN and firewall modernisation, cybersecurity controls uplift, and disaster recovery validation — designed with governance that stands up to audit from day one.

## Design highlights

- **Contract-term aware:** 18-month delivery leaves a 6-month buffer before M24 for knowledge transfer, documentation and closure
- **Cutover governance:** G3 Cutover Readiness requires five mandatory signatories with pre-briefed alternates; one "no-go" stops the wave
- **Security by design:** EDR, vulnerability SLAs, encryption and segmentation reviewed at every gate; control traceability is a gate criterion
- **Financial discipline:** Tiered contingency draw-down authority (PM → SteerCo → Technology Group) with mandatory logging
- **Vendor accountability:** Quarterly scorecards with SLA breach remedies and contractual escalation paths
- **Audit-ready:** Evidence repository with structured hierarchy, ISO 27001/MAS TRM control mapping, and 7-year retention
- **Clean handover:** M18 closure pack with 12 mandated items ensures zero open items at contractor exit
